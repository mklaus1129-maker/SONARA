# SONARA — первая демо-версия

Статический интерфейс сайта. Откройте `index.html` в браузере.

Сейчас можно ввести название и текст/идею песни, выбрать вокал, стиль и настроение, добавить идею в список на странице.

Важно: генерация аудио, аккаунты и постоянное сохранение пока не подключены. Это UI-прототип, а не готовый генератор музыки.
